# Haven Home

Create a premium luxury furniture e-commerce website. Use a warm beige, walnut brown, and off-white color palette. The design should feel similar to high-end brands like West Elm and Restoration Hardware. Include a full-screen hero section with elegant typography, category cards for Living Room, Bedroom, Dining Room, Office, and Outdoor Furniture. Add a featured products section, customer testimonials, room inspiration gallery, about section, WhatsApp contact button, and footer. Use large imagery, smooth animations, rounded corners, subtle shadows, and lots of white space. The website should be fully responsive and optimized for mobile devices and laptops too
